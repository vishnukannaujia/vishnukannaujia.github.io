Evalplane

How often do AI agents break their own rules? It depends on how you read the rule, by as much as 35×.

  • Audited 4,448 published τ²-bench agent trajectories across airline, retail and telecom, offline and with zero model calls.
  • Found runs the benchmark scored as solved in which the agent still broke a stated policy, and showed the rate moves 35× in retail and 70× in airline depending on one modelling choice.
  • Reproduced an independent project's published numbers exactly, credited prior work up front, and recorded my own corrected figures in the write-up.
  • Ships as a CLI that turns each agent rule into a deterministic check and fails CI when one fires. 361 tests.

f1-fantasy

A retrieval and LangGraph tool that recommends a budget-legal F1 Fantasy team, with every design choice settled by a measured comparison.

  • The model proposes a team; plain Python enforces the $100M budget and sends exact errors back for up to two retries.
  • Ten eval scripts cover chunking, embeddings, reranking, generation quality, routing and prompt injection from live web results.
  • Tested nine chunking strategies and three embedding models; tested a reranker and rejected it when recall got worse.
  • Predictions are scored against real race results, and lessons feed back through an evidence-weighted ledger.

Trazer

A voice assistant for your laptop that keeps listening while it works, because every task runs in a background subagent.

  • Speech recognition, speech synthesis and voice detection all run on the machine; the language model is the only remote part and can be swapped for a local one.
  • You can interrupt it mid-sentence: detected speech cuts playback immediately.
  • Nine switchable voices across six languages, changed by voice command.
  • Shell and file actions are permission-classified and need spoken confirmation; every model call is traced locally.
